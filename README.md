Entry for the make.fun bounty [Make the Judge Laugh in One Line](https://make.fun/bounty/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21).

`main.py` (Python stdlib only) writes exactly one funny line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`:

> My dating profile says I'm mysterious; my only match asked if I was a bot selling crypto.

One line, 89 characters, no setup to explain — the punchline lands on
the last word.
